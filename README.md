# Geometriai Számológép

Python alapú geometriai számológép, amely síkidomok és 3D testek
területét, kerületét, felszínét és térfogatát számítja ki.

## Funkciók

### Síkidomok
- Négyzet – terület, kerület
- Téglalap – terület, kerület
- Kör – terület, kerület

### 3D Testek
- Kocka – felszín, térfogat
- Téglatest – felszín, térfogat
- Gömb – felszín, térfogat
- Henger – felszín, térfogat

## Futtatás

```bash
python geometria_orokles.py
```

## Projekt struktúra

| Fájl | Leírás |
|---|---|
| `geometria.py` | Függvény alapú megoldás |
| `geometria_osztalyok.py` | Osztály alapú megoldás |
| `geometria_orokles.py` | Öröklés, hibakezelés, fájlba mentés |
| `geometria_3d.py` | 3D testek |
| `geometria_fo.py` | Egyesített program, kétlépcsős menü |
| `test_geometria.py` | Egységtesztek |
| `geometria.drawio` | Folyamatábra |

## Tanult fogalmak
