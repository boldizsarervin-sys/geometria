# Geometriai Számológép

Python alapú geometriai számológép, amely síkidomok és testek
területét, kerületét számítja ki.

## Funkciók

- Négyzet – terület, kerület
- Téglalap – terület, kerület
- Kör – terület, kerület

## Futtatás

```bash
python geometria_orokles.py
```

## Projekt struktúra

| Fájl | Leírás |
|---|---|
| `geometria.py` | Függvény alapú megoldás |
| `geometria_osztalyok.py` | Osztály alapú megoldás |
| `geometria_orokles.py` | Öröklés és hibakezelés |
| `geometria.drawio` | Folyamatábra |

## Tanult fogalmak

- Változók, input, print
- Függvények
- Osztályok és öröklés
- Hibakezelés (try/except)
- Git verziókövetés
